# Marieta

A personal nutritional meal planner. Plans weekly menus against dietary targets using a constraint solver, tracks ingredients and their nutrient profiles, and generates shopping lists.

## Stack

| Layer | Tech |
|---|---|
| Backend | Python · FastAPI · SQLAlchemy 2.0 async · PostgreSQL |
| Frontend | Angular · Angular Material · NgRx Signal Store |
| Solver | OR-Tools CP-SAT |
| LLM | Ollama (`gemma4:latest`) |
| Export | WeasyPrint (PDF) · odfpy (ODS) |
| Infra | Docker Compose |

## Status

Work in progress. Single-user, local deployment only.
